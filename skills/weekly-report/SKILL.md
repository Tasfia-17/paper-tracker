# Weekly Report

Generate the weekly paper digest report.

## Steps

1. Read all digest entries added this week from `knowledge/papers.md`
   (filter by date: entries from the last 7 days)

2. Read `memory/MEMORY.md` for researcher context

3. Generate the report in this format:

```markdown
# 📚 Paper Tracker — Week of {date}

> {N} new papers found across {M} arXiv categories

## 🔥 Must-Read This Week
{papers with score 5, full digest entries}

## ⭐ Highly Relevant (Score 4)
{papers with score 4, full digest entries}

## 📌 Worth Knowing (Score 3)
{papers with score 3, condensed to title + one-line reason}

---
## 📊 Stats
- Papers scanned this week: {total checked}
- Papers added to knowledge base: {N}
- Total papers tracked (all time): {from memory}
- Categories monitored: cs.LG, cs.CL, cs.CV
- Next run: {next scheduled date}

---
*Generated by paper-tracker · [View knowledge base](../knowledge/papers.md) · [Update your profile](../memory/MEMORY.md)*
```

4. Save the report to `reports/YYYY-MM-DD.md`

5. Print the full report to stdout so it appears in the terminal

6. If any score-5 papers were found, print a prominent alert:
   ```
   🚨 ALERT: {N} must-read paper(s) found this week — check reports/{date}.md
   ```
